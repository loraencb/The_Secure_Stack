This file is kept as a compatibility pointer.

The canonical project documentation lives in:

- [README.md](./README.md) for the platform overview, architecture, setup, testing, and current feature set
- [DEPLOYMENT.md](./DEPLOYMENT.md) for Docker, environment configuration, Alembic migrations, and deployment flow

Current Secure Stack capabilities include:

- multi-user authentication and per-user ownership
- guided lab sessions with `Overview`, `Guide`, `Workspace`, and `Reports`
- topology-aware lab manuals and structured task metadata
- adaptive AI tutoring with progressive hints and Ask Tutor actions
- evidence-aware findings and report generation
- durable session history, timeline, and workflow state
- formal lab schema validation and backward-compatible lab normalization
- containerized deployment with health checks, migrations, and environment-based configuration

Use [README.md](./README.md) as the primary source for future updates.
